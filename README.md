## Featured work

### [DeepSafe — AI Deepfake Detection](https://github.com/saqibtariq22/DeepSafe)

Full-stack deepfake detection system. Uses **XceptionNet** for frame-by-frame video analysis and **AASIST** (spectro-temporal graph attention) for audio deepfake detection. Ships with user authentication, admin dashboards, interactive charts, PDF report export, and a dark cyberpunk UI.

![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white) ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB) ![PyTorch](https://img.shields.io/badge/PyTorch-EE4C2C?style=flat-square&logo=pytorch&logoColor=white) ![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white)

### [Web UX & Performance Analyzer](https://github.com/saqibtariq22/Web-UX-And-Performance-Analyzer)

Paste a URL and get scored on **page speed**, **SEO**, **mobile-friendliness**, and **accessibility** — with specific fix recommendations. Full JWT auth system, analysis history, user dashboards, downloadable JSON reports, and dark mode support.

### [Multilingual News Analysis Platform](https://github.com/saqibtariq22/multilingual-news-platform)

NLP engine that runs **8+ transformer models** on any news article — sentiment analysis, emotion detection, summarization, named entity recognition, topic classification, keyword extraction, and credibility scoring. Supports text input, URL, file upload, and RSS feeds.
